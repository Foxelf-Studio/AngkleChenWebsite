## 工具链一览

| 环节 | 工具 | 说明 |
| --- | --- | --- |
| 灵感收集 | 备忘录 / 骰子日记 | 随时随地记一句话 |
| 写作 | Obsidian | 双链 + 模板 |
| 版本管理 | Git | 每篇文章一个 commit |
| 发布 | 静态托管 | push 即发布 |

## 为什么是 Markdown

1. **纯文本**，十年后还能打开
2. **无格式干扰**，写作时只关注内容
3. **可编程**，批量处理很爽

## 写作时的三个习惯

- 先写大纲，再填血肉
- 卡住就跳过，绝不死磕
- 写完放一晚上再读一遍

## 代码示例

一篇文章的 frontmatter 长这样：

```yaml
---
title: 文章标题
date: 2026-08-05
tags: [写作, 工具]
---
```

然后在任何支持 Markdown 的平台上都能渲染。

## 小结

工具不重要，重要的是**写**。但如果工具能让你少一次分心，那就是好工具。
