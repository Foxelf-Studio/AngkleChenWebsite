## 从一个念头开始

用了三年的白底黑字主题，某个深夜突然觉得：太亮了。亮得像医院的走廊。

我想要的感觉是——**深夜坐在窗边，玻璃上映着城市的微光**。于是有了这次改版。

## 玻璃没有颜色

Apple 在 Liquid Glass 的设计规范里有一句话我很认同：玻璃从内容层取色，自己保持中性。

真实的玻璃是没有颜色的。它只是：

- **借用**背后的光
- **弯曲**穿过它的光
- **柔化**一切边缘

所以这个博客的面板只用 5%–12% 的白色透明度，所有颜色都来自背景里那几个柔和的光斑。

## 光有方向

真玻璃和「半透明色块」的分界线，在于**光的方向**：

```
顶边受光 → inset 0 1px 0 白色高光
底边背光 → inset 0 -1px 0 深色暗缘
```

少了这两笔，玻璃就死了，变成一块脏兮兮的塑料。

## 最后

加上 2.5% 的噪点颗粒，塑料感消失了。整个页面安静下来，像深夜的窗台。

> 设计不是加法，是把多余的光关掉。
