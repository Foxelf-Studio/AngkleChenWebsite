## 第一次编译失败

人生第一个 Rust 程序，连编译都没过：

```rust
fn main() {
    let s = String::from("hello");
    let t = s;
    println!("{}", s); // borrow of moved value: `s`
}
```

当时的心情：**什么鬼？赋个值而已！**

## 顿悟时刻

第三天，看到一句话：

> 所有权 = 唯一的责任方。

`s` 把字符串的所有权**移交**给了 `t`，从此 `s` 失效。这就像把钥匙交给别人，自己就不能再开门了。

## 借用检查器是个好老师

它不让你写出的代码：

- 悬垂引用
- 数据竞争
- 重复释放

这些东西在 C++ 里都要用血泪来换。

## 一周后的心态

编译器从**敌人**变成了**结对编程的搭档**。它严格，但它是对的（大多数时候）。

下一步：啃生命周期。祝我好运。
